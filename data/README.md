# Vendored dumps

Property dumps for three BL2 objects, fetched with
[ft-explorer](https://github.com/apocalyptech/ft-explorer) at commit
`29a24d28d46428ffb6a717f7dabba7ea3882aad0` (2019-06-26).

- `WeaponPartDefinition.dump.xz`
- `WeaponPartListCollectionDefinition.dump.xz`
- `WeaponBalanceDefinition.dump.xz`

The files are xz-compressed to keep the repository small. Decompress with
`xz -dk <file>` if you want to inspect them.
